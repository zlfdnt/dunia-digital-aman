# Menjelajahi Dunia Digital dengan Aman
Media belajar interaktif Koding Bab 2 (SMP Kelas VII). Frontend statis (HTML/CSS/JS vanilla) + backend REST API Google Apps Script.

- `index.html` — satu halaman (SPA, routing hash)
- `js/config.js` — **satu-satunya** yang perlu diedit: isi `GAS_URL` dengan URL Web App (/exec)
- `js/data-preview.js` — konten untuk mode pratinjau tamu (tanpa kunci jawaban)
- `assets/img/` — ilustrasi SVG untuk slideshow (tambah/ganti gambar di `js/landing.js`)

Cara memasang: lihat `PANDUAN-INSTALASI.md`.
